# StudyHelper

Русскоязычный многопользовательский Telegram-бот.

## Функции
- Домашние задания: добавить, посмотреть все/сегодня/просроченные/выполненные, отметить, изменить, удалить.
- Дела на день: отдельный список для каждой даты, история; незавершённые дела не переносятся.
- Напоминания о делах каждые 30 минут в выбранном интервале.
- Расписание Пн–Пт: добавление, изменение, удаление уроков.
- Напоминания о ДЗ: включение, дни недели, частота 30/60/120 минут или ежедневно, временное окно.
- Напоминания об уроках за 5/10/15/30 минут или выключить.
- Часовой пояс, статистика, индивидуальные данные пользователей.

## Ubuntu
Требуется Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
python bot.py
```

В `.env` укажите токен от @BotFather в `BOT_TOKEN`.

## Хостинг
Команда запуска: `python bot.py`. Используйте постоянный worker/service и постоянный диск для файла SQLite. Установите переменную окружения `BOT_TOKEN`. Не запускайте две копии с одним токеном и одной базой. Пользователь должен сначала нажать Start в чате с ботом.
