# StudyHelper

Русскоязычный Telegram-бот для домашних заданий, ежедневных дел, школьного расписания и напоминаний.

## Возможности
- Раздельные данные пользователей Telegram.
- Домашние задания: добавить, просмотреть, отметить выполненным, удалить.
- Дела на день: отдельный список для каждой даты; прошлые дела не переносятся автоматически.
- Напоминания о делах каждые 30 минут в выбранном временном окне.
- Расписание на понедельник–пятницу.
- Настраиваемые напоминания о домашних заданиях: дни недели, частота, временное окно.
- Часовой пояс пользователя.
- Статистика: всего, выполнено, ожидает, просрочено и процент выполнения.
- SQLite с автоматическим созданием таблиц.

## Запуск на Ubuntu
1. Установите Python 3.11 или новее.
2. Распакуйте архив и откройте терминал в папке `StudyHelper`.
3. Создайте окружение:
   `python3 -m venv .venv`
   `source .venv/bin/activate`
4. Установите зависимости:
   `pip install -r requirements.txt`
5. Создайте `.env` на основе `.env.example` и вставьте токен от @BotFather.
6. Запустите:
   `python bot.py`

Бот должен работать постоянно. На хостинге задайте переменную окружения `BOT_TOKEN` и подключите постоянный диск/том для папки `data`. Не храните базу SQLite на эфемерном диске.

## Команды
- `/start` — открыть меню
- `/cancel` — отменить текущий ввод

## Важно
Бот отправляет личные уведомления только после того, как пользователь сам открыл чат с ботом и нажал Start.
